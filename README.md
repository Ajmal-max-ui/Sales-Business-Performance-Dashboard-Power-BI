# Sales-Business-Performance-Dashboard-Power-BI
Built an interactive Power BI dashboard to analyze sales and business performance.<br>

• Created KPI cards for Total Revenue, Total Cost, Total Profit, Total Orders, and Total Customers<br>
• Used Power Query for data preparation and transformation<br>
• Created DAX measures for business KPIs<br>
• Added interactive charts, slicers, and filters<br>
• Analyzed sales, profitability, and performance trends<br>
